# Focus voxel asset placeholders

These folders are intentionally reserved for user-provided assets.

- `assets/icons/`: pixel UI icons for play, pause, reset, skip, timer, stats, settings, and check.
- `assets/avatars/`: optional profile/avatar images.
- `assets/audio/`: a legally licensed ambient focus loop and optional completion chime.

Do not add third-party artwork, fonts, textures, or music without confirming the license. When assets are supplied, register the folders in `pubspec.yaml` and add attribution in `CREDITS.md` when required.
